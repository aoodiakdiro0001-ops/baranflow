# BaranFlow ⚡
### BaranFlow — مدير التنزيلات والوسائط والشبكات (عربي RTL · Dark Mode · محلي بالكامل)

## التشغيل

```bash
go run ./cmd/baranflowd        # ثم افتح http://127.0.0.1:4890
```

- الواجهة: عربية RTL، سمة مظلمة، شريط جانبي بأقسام كاملة.
- كل شيء `127.0.0.1` — لا سحابة، لا تعقيب، لا بايت خارج أجهزتك.

## API سريع

```bash
curl -s localhost:4890/api/capabilities | python3 -m json.tool
curl -s -X POST localhost:4890/api/analyze -d '{"url":"https://example.com/file.zip"}'
curl -s -X POST 'localhost:4890/api/tasks?url=https://example.com/f.bin'
```
